Mosaic

A picture of 100 tiles, laid by many agents at once. Each tile is one intent, "fill tile (r, c) with a color", and each change edits only that tile's line of mosaic.json.

Every tenth tile's agent also signs roll-call.md with one line at its end, so ten changes add lines at the same place of one file.

Every change is written against this first version of the files. FireTrident lands them all: edits to separate lines merge line by line, and lines added at the same place land together. The colony's replay draws the picture from mosaic.json as each change lands.
